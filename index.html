¿Cómo Entrar a SYLENMC?

Selecciona tu plataforma para ver los pasos de conexión exactos.

1

Copia la Dirección IP

Para Java Edition solo necesitas copiar esta dirección:

sylenmc.diavlohosting.com
2

Añade el Servidor

Abre Minecraft Java > Multijugador > Añadir Servidor y pega la IP en la casilla Dirección del Servidor.

3

Regístrate e Inicia Sesión

Una vez dentro del lobby, usa estos comandos en el chat (Tecla T):

/register [tu contraseña] [confirma tu contraseña]

/login [tu contraseña]
1

Datos de Conexión Bedrock

En Bedrock debes ingresar la IP y el Puerto correspondiente:

IP: sylenmc.diavlohosting.com
Puerto: 19016
2

Guardar Servidor

Ve a Jugar > Servidores > Añadir Servidor. Coloca el nombre SYLENMC, pega la IP y el puerto 19016 y dale a Guardar.

3

Regístrate en el Juego

Abre el chat e ingresa tus datos de registro igual que en Java:

/register [tu contraseña] [confirma tu contraseña]
